⚙️ Configuración de precios

costo + IVA = Lista 4 / (1 + factor L4)  ·  costo neto = (costo + IVA) / (1 + IVA)  ·   Lista n = round(costo neto × (1 + IVA) × factor Ln). El factor de la L4 se deriva solo (1 + inversa / 100).

📡 Modo de sync

/api/v1/sync (v1) no cambia nunca: las apps viejas siguen recibiendo exactamente el JSON actual. El modo solo decide qué responde el contrato nuevo.

⏪ Rollback

Deshacé el último reemplazo del catálogo. El actual se guarda en el otro backup (nunca se pierde) y sube la revisión: todas las apps se resyncan solas.
